# Changelog

## 1.0.0 — 2026-11-02

Initial public release of design-studio. Successor to the standalone `design-skill` and `AI-Design-Skill` repos.

- **Added.** Router (`SKILL.md`), doctrine (`workflow`, `principles`, `conflicts`, `gate`), install/sync/doctor tools, slop-landing fixture.
- **Vendored.** taste-skill, Impeccable, ui-ux-pro-max, ai-design-review, frontend-slides + beautiful-html-templates, diagram-design. Pins in `sources.lock.json`.
- **Changed vs standalone predecessors.** One skill folder; vendored `SKILL.md` files renamed to `MODULE.md`; database picks pass the slop floor; Impeccable pin/unpin disabled; Windows `python` fallback.
